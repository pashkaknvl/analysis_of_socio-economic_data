# Анализ социально экономических данных
## Постановка задачи
Необходимо исследовать социально-экономические данные по 85 регионам России, изучить особенности их распределений, выявить наличие выбросов и подготовить всё к дальнейшему корреляционному, регрессионному и кластерному анализам. В фокусе — взаимосвязи между уровнем доходов, масштабами добычи, безработицей и долей населения с доходами ниже ПМ.
## Описание показателей
- population — численность населения (чел.)
- income — среднедушевые доходы (руб./мес.)
- unemployment_rate — доля безработных (%)
- extraction — добыча полезных ископаемых (млн руб.)
- poor_share — доля населения с доходами ниже ПМ (%)
## Рабочие гипотезы
«Чем выше income, тем ниже poor_share» (отрицательная связь).
«Объём extraction позитивно коррелирует с income» (ресурсные регионы имеют более высокие доходы).
«Сильные различия в population влияют на уровень безработицы и бедности» 
## Техническая реализация
- SPSS
- Python (Matplotlib, Pandas)
